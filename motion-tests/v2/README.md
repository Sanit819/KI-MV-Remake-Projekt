已完成：[带声音的30秒动作试验](index.html)。3840×2160／60fps／1800帧，MP4与FLAC MKV均通过全解码与时间戳核验，720p完整实际播放与两个换姿短窗慢放检查通过。使用原曲 **01:12.5–01:42.5** 的连续30秒，展示花的独立风动、根点固定、盆与环境分层，以及Rex的完整姿态切换和独立云层运动。它是动作机制与节奏验证，不是已经锁定歌词的正式片段。

## 连贯感如何实现

- 一个动作使用前态、变化态、后态，共用花根／肩部等锚点；姿态的改变具有明确方向。镜头在动作之间承接视线与速度。
- 原画主体、前景、环境与镜头分别运动。花围绕根点摆动，盆固定；人物动作与远方云流相互独立。
- 安静段让局部运动保留低频停顿；推进段缩短动作间隔；增强段让连续位移、镜头和环境每秒更新60次。三张人物关键画仍然是三张，不能把变换插值称为60张手绘原画。
- 强瞬态只辅助局部光影、风速和动作重音。切镜放在动作段落或音乐转折，不把每个峰值都变成剪切、闪白或震屏。

这继承第一企划实际使用过的“多姿态、锚点对齐、分层、绝对时间渲染”方法，第一企划的归档文件没有改动。完整66镜动作分级与后续扩展见 [伪动画方案](../../docs/PSEUDO_ANIMATION_V2.md)。

## 音乐依据

原曲这30秒首尾短时响度增加约5.52 LU；以统一阈值计数的强混音瞬态由约0.90增加到2.43次／秒。分析不是鼓轨分离，峰值也可能来自人声、弦乐或其他打击声，未作直接耳听认证。完整曲线、方法和区间依据见 [rhythm-v2](../../references/rhythm-v2/REPORT.md)。

局部包络是根据测量制定的创作控制，不是把全曲机械分成三个等长阶段。实际制作时还须按歌词、完整动作和情绪峰谷定时，托付与告别可以在音乐高潮中保留停顿。

正式歌词JSON仍未填写不可靠时间码。样片不加猜测的逐句歌词，不混入游戏对白，不改变原FLAC，也不转ALAC。
