# Hortus Regis Alti 崇高君王之苑

第二企划，开始于 2026-11-06。用户已明确制作粉丝向同人 MV，以 FCU Joker 队与索托亚 Shadows／Moon 11 的角度呈现故事，授权助手决定剧情。**最新指示允许两侧交替作为叙事主体，Rex 不必始终是主角；每段贴近歌词与意境，人物与机体遵循已核对设定，飞机严格依据对应三视图绘制。**

**当前优先入口：[带音乐的画风试听页](style-tests/v1/index.html)／[8人官方参考浏览页](references/characters/index.html)。** 用户最新要求先完成官方人设收集与参考画风试片，尚未选择最终画风。已生成三组镜头及 Joker 的二维修订，合辑38.3秒，4K60输出；单段另有FLAC音轨母版。生成原画1672×941，放大输出，不称原生4K绘制；人物暂未动画。详情见[试片说明](style-tests/v1/README.md)。

[可筛选分镜阅读版](storyboard/index.html)／[66 镜逐句分镜 v2](docs/STORYBOARD_V2.md)仍为剧情基线，覆盖16组歌词。Rex 的身份承接保留，Tewy与其他人物拥有独立主观段落。完整歌词实际起止仍待对时，没有完整成片；旧[剧情v1](docs/STORY_TREATMENT_V1.md)保留为历史。

人物机号、阶段配机与原作时序见[连续性表](docs/CONTINUITY_V2.md)；绘机前使用[三视图规范](docs/AIRCRAFT_DRAWING_SPEC.md)与[参考档案](references/aircraft/README.md)。本地原始参考图已另存，三视未齐的型号明确保留缺口。

本轮补齐X-40设定书正投影及游戏对照、Su-57基线核验、F/A-18F同尺度核对；参考可用范围与保留限制已经更新，所有正式机体资产的几何／涂装验收标记仍为false。用户本机没有游戏。官方人物共8位，37份独立图片（官网、设定书扫描、3张游戏实录分别标注）；Rex没有取得具名露脸人设。

背景依据：[首轮研究汇总](RESEARCH_SUMMARY.md)。前三支用户指定视频的全时段字幕／画面采样、官方背景补充和阅读边界均已整理。

**新增素材：[用户原曲与歌词](MATERIALS.md)。** 已保留 FLAC 原件副本（48 kHz／16-bit／双声道，5:50.769）和 16 组双语歌词；本企划不安排 ALAC 转换。
