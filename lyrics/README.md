# 用户提供歌词

`user-provided.txt`保留2026-11-07用户消息中的3行制作署名、58组日中歌词和末尾结束标记。文件采用UTF-8与LF换行，不进行译文校订、注音清理或重复段合并。

`lyrics.json`按顺序登记L001–L058，`ja`和`zh`分别对应原文件中的两行；`source_lines`为原文件1起算行号。每个重复日文仍是独立条目，因此用户在重复句中提供的不同中文译法也保留。

当前全部`start`和`end`为`null`。未来时间轴以用户FLAC的第一个样本为0秒；参考MV已有时码属于另一来源，移用时依据`docs/AUDIO_REFERENCE_COMPARISON.md`的映射，不能把约84毫秒的整轨偏移冒充逐句词界对齐。

重建结构化文件和音源核验使用`python tools/register_song_materials.py`（在项目根目录执行）。原文文件不可被后续对齐流程自动改写；校订须另存提案并保留用户原稿。
