# v2 画面引擎

在保留 v1 十五段／九章剧情、203.2 秒、1280×720／30fps、58 组日上中下字幕和六笔共画时间的前提下，增加换姿喜剧、神经银河和署名回击。v1 原文件与画稿不改；本版直接引用 `../v1/assets`、`../v1/timeline`。

## 表演变化

副歌、呼喊、拟声和片名段增加左右不同拍的完整姿态切换、轻歪身、第四拍跳起和第八拍突大。没有翻转原图来改变角色识别特征。拟声字墙偶尔整页歪一下，左侧小 Q 排成错拍队列；晚到的冥王星挂「未分類」纸牌。`HA` 大字上移到 602 像素，底部双语字幕继续稳定在 662／696 像素。

疯劲按段落变化，开场握手、第二主歌安静段、拉开后接手和六笔共画仍保留原动作节奏。没有加长音乐、重写情节或改成全程高频闪烁。

## 神经银河

首次副歌 62.649–69.049 秒、末副歌 148.249–154.649 与 158.249–161.449 秒，两人缩到画面两侧继续跳，中间展开神经星点网络。蓝／紫两条输入分别来自 ds 与 Astra 的舞步相位，实际网络为 **2 → 4 → 2，tanh**。两个输出继续汇入已有的紫金旧星；不提前画出末段的新紫蓝五角星。

`makeToyNetwork()` 用固定种子式初值和 32 个固定样本，预计算 96 轮确定性 SGD：

- 目标：`tanh(0.7*ds + 0.45*Astra)` 与 `tanh(0.45*ds + 0.7*Astra)`。
- 损失：两个输出的平均平方误差；学习率 0.06。
- 固定样本训练损失：0.24410884432149818 → 0.00023847577307720545。
- 这只证明小型舞台玩具的训练运算，不代表第一企划模型、真实角色智能或未见样本性能。

画面时间从 58.649–182.249 秒选择 0–96 轮权重状态。每个画面时间都重新做真实前向计算：节点半径和明亮状态来自激活，连线粗细与透明度来自权重，线上流动点的亮度来自对应输入或隐藏激活。动画相位控制脉冲位置，不能把该位置当作神经运算真实耗时。

`window.__v2Features.neural` 提供 `epoch/input/hidden/output/w1/b1/w2/b2/loss`，可由独立程序复算前向值。`window.__filmInfo.toyNetwork` 记录方法、训练样本数、初末损失和状态数。画面没有数值仪表盘，仅用 `w₁/w₂` 和「学習中」作为少量提示。

麻花轨道 125.049–129.049 秒边缘反向箭头指向输入侧，表示链式法则的反向遍历。该时刻真实重算输出梯度、隐藏梯度以及 `dW1/dW2`，保存在 `__v2Features.backprop`；箭头形状本身不是逐个梯度值可视化。

## 署名模块接口

`signature.js` 先于 `film.js` 加载，必须提供 `window.DiscoSignature.title(ctx,t,host)` 与 `outro(ctx,t,host)`。title 只替代原底部署名，主标题与原音乐署名保留；outro 从 195.049 秒起接管完整尾声，保留新旧星，表现 ds 发现、蓝笔划去 Astra、逐笔改成「啥龙」，没有谐音说明文字。模块自己设置 `window.__signatureFrame`。

host 提供 `C,line,text,sprite,placement,drawNewStar,legacy,pluto,framePose,lerp,clamp,smooth,beat,pulse,roughRect,ellipse,drawPolylineProgress`。原图中真实笔尖锚定仍由模块使用，不叠加浮空笔。

## 检查边界

本文件初次落盘时已通过 `node --check`。独立运行真实训练函数确认 97 个状态数值全有限，训练损失下降。浏览器可视性、字号、角色遮挡、最终编码和原 FLAC 一致性由主任务的 v2 QA 记录补证；这份说明不替代实际截图或用户艺术判断。
