# 第一版候选时间线

本目录供完整 **203.2 秒、720p30（6096 帧）** 第一版调度。时间零点是用户提供 FLAC 的首个样本。成片沿用原 FLAC 流；分析只在内存临时解码，没有改写母版。

`lyrics-candidate.json` 是制作候选，**并非正式逐词或逐音素对齐**。正式 `lyrics/lyrics.json` 的 58 组 start/end 继续为 null。候选保留用户日文、中文以及重复拟声文本，不以 ASR 识别结果改歌词。

## 读取接口

```js
const cue = lyrics.entries.find(e => e.start <= t && t < e.end);
// cue: {id, ja, zh, start, end, scene_id, action, timing_evidence, ...}
// t 是 FLAC 秒；无 cue 时处于明确留白或片名/尾声。
const beats = rhythm.beats; // 数值数组，FLAC 秒
const amplitude = rhythm.normalized_rms_30fps[frame]; // 6096 项
```

- `start/end` 是字幕和情节的显示窗口，end 不代表实际人声收尾。
- `reference_start_frame/reference_end_frame` 为原参考 MV 的零基帧号，右端不含。
- 移用关系：`FLAC秒 = 参考MV帧号 / 30 - 0.084125`。偏移来自现有音轨互相关比对，见 `docs/AUDIO_REFERENCE_COMPARISON.md`；不能把原 MV 时码不加转换地用于 FLAC。
- `chapters` 与既有剧情九章一一对应；`gaps` 指定空白、片名与尾声；`drawing_window` 指定实际共画时段。

## 视觉依据与保留的不确定性

已查阅全部九张 1 秒总览、既有连续全帧审阅记录，并选取关键原帧复查。大多数句首使用原 MV 对应歌词的首次字幕/排版段起点；部分在清场之后数帧才出现完整文字。L002 特别复查了 f148/f149：f149 才开始出现「あなたとダンスを」。L045 的 f4450 是巨大「ねえ」、f4462 才是「何」；不能把后者当整句起点。

这些视觉锚点只证明画面如何配词。没有声称逐句耳听，也没有声称所有标注都是人工逐帧确定的准确发音起点。实际起唱可以早于字幕出现。

两段 na-na 原 MV 使用文字墙、多次重复，用户给每段三组文本，两者不能直接一字一屏对应。L026/L027、L057/L058 的内部分界明确标为 `editorial_repeat_cluster_estimate`：按 8 拍单位分成制作段，末组吸收余下重复，不作为词级卡拉 OK 时间。最后段从 182.249 秒起进入拟声，共画建议从 **185.449 秒** 开始，至 **195.049 秒** 前完成，给交替轮廓、闭合、蓝尾和紫色额外小弯约 **9.6 秒**。

## 声学节拍

`rhythm-analysis.json` 来自 FLAC 临时解码的单声道 24 kHz 测量：librosa 频谱通量、10 ms hop、自相关、相位扫描。整曲最强候选为 **150 BPM（0.4 秒/拍）**；每个 20 秒窗口单独记录主峰及相位。150 BPM 的固定候选同时符合原 MV 常见每 12 视频帧换姿的节律。

供渲染读取的 `beats` 是校准后的规则网格：`0.020 + n × 0.400` 秒。它与实测 `onset_peaks` 分开存储；不能将规则网格说成每个拍点都被人工核验。部分窗口相位偏好 0.220 秒，是半拍强弱歧义；不据此推断小节首拍。`downbeats` 留空。

原始谱峰的抛物线插值约 150.19 BPM 属于短窗频谱估计，不取代无明显累计漂移的 150 BPM 制作候选。该分析没有分离人声/鼓组，也没有实际耳听确认。`normalized_rms_30fps` 用于小幅视觉能量变化，不是响度母带处理。

## ASR 交叉核对结果

已用本地 faster-whisper large-v3 对完整 FLAC 自动识别。原始结果保留在 `asr-candidate.json`，其文字错误较多，并在片名间奏、na-na 段及结尾出现虚构词句，**不用于替换用户歌词，也不用于填补这些段落**。自动识别到的较清楚句段与视觉结构一致，例如 L001 约 0.80–4.64 秒，L036 约 122.84–124.04 秒，L040 约 132.64–135.24 秒，L042 约 138.94–141.62 秒。视觉开始与自动词边界可相差约 0.1–0.4 秒；本版保留原 MV 视觉语法的显示候选，不据 ASR 声称准确发音起点。

ASR 没有可靠解出两段 na-na 的逐组边界，因此仍保留四个明确标注的内部剪辑估计。尾声 ASR 的“感谢观看”是假识别，绝不能作为歌曲原词上屏。

## 本地复现

在项目目录运行：

```powershell
& '..\vocaloid-style-mv-pipeline\.venv\Scripts\python.exe' -X utf8 tools/analyze_music_v1.py --lyrics --rhythm --verify
```

工具复用 pipeline 已安装的 Python、FFmpeg、librosa；不安装或更换系统依赖。可选 `--asr` 使用其已缓存的 faster-whisper large-v3，写 `asr-candidate.json`，仅提供自动识别的额外交叉参考，不覆盖本目录视觉候选或正式歌词。原环境 faster-whisper/PyAV 对 `metadata_errors` 参数不兼容，工具使用 FFmpeg 内存 PCM 输入避开该问题，没有修改共享环境。

输入、产物、证据边界与验证记录见同目录 JSON；无用户确认的推断不得升级成正式对时。
