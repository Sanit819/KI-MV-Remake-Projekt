# 新参考早段：0–80 秒的可见机制与改法

2026-11-05。来源为野生大K的 [BV1Jwhy6BEMJ](https://www.bilibili.com/video/BV1Jwhy6BEMJ/)，并非此前紫色龙娘参考 BV1RzHG6SEHy。公开副本 852×480 / 24fps，视频首帧 PTS=0.021s。下列原片时间均为 `0.021 + 零基帧号/24`；ASTRA 时间为原曲内时间，新的警告投稿版另加 5 秒。

本片早段主要采用琥珀字符终端，字符既组成数据，又组成几何、体积和大字。外层圆角终端框基本稳定；运动主要发生在其中的字符、队列、线与图形。没有拿到其渲染工程，下面不把外观推断当作实际实现。

## 逐段观察与可迁移演法

### 1. R01–R05：参数必须流到正在生成的世界

[同音乐对照 R03](boards/R03.jpg) · [连续帧](motion/R03.jpg)

参考 f195/229/262（8.146/9.563/10.938s）里，原本稀疏的矩阵逐行变满；f178–189 还可见对象平面结束后，参数页开始从顶端写入；f261–272 则从满页收暗，进入新的控制框。可见的是明确的填充前沿和状态交接，不能据此断言具体使用了哪一种粒子算法。

我们此时是完整聊天窗中的配置表与百分比。信息正确，但面板始终固定，名字和数值变化只占小块区域。建议保留用户指定的真实工作区外观，镜头先靠近正在写入的参数；每个已确认字段沿一条明确线路成为世界的一个结构：名字变为标识，位置参数变为脚下网格，记忆字段留下旧星记录。阶段完成后，界面退到边缘，给正在生成的主体让位。验收：关闭说明文字也能看懂“输入正在构成她的世界”。

### 2. R06–R08：同一材料从问题变成世界

[同音乐对照 R06](boards/R06.jpg) · [连续帧](motion/R06.jpg) · [标题形成概览](overview/overview-03.jpg)

参考 f400–413（16.688–17.229s）中，整片字符场形成不断改变的斜向条带和弧面；f528/540/552（22.021/22.521/23.021s）由散点聚出标题。字符从“内容”变成“空间”再变成“文字”，视觉材料连续。

我们 R06 的三个实帧仍是完整聊天页，真正有情绪的删改输入在很小的输入框内。建议把输入框推近到画面宽度约 65%，只保留一句输入、一次停顿、一次修改；光标下一次落笔带出紫色路径，路径穿出输入框，接到第一颗歪星。可以借鉴字符重组机制，但保留我们“对方真的带来新变化”的故事，不能用随机噪点替代那一笔。验收：输入变化在手机预览能读到；星的起点沿用前镜光标位置。

### 3. R09：让维度变化成为镜头的变化

[同音乐对照 R09](boards/R09.jpg) · [连续帧](motion/R09.jpg)

参考 f716/752/788（29.854/31.354/32.854s）从散点到斜线再到体积。f769–780（32.063–32.521s）显示铺满画域的平面结构突然收成中央小体积，大小反差本身承担重音。

我们已经有点、线、方体，保留这个语义。建议旧星的一个顶点成为第一颗点，散点沿此前笔迹形成一条线；镜头升起，线展开为路网；立方体撑起后成为一座可继续绘制的房间。每次改变维度，也改变观看角度或前后遮挡。验收：点的身份连续；0D/1D/2D/3D 标签与实际几何匹配，不只换字幕；镜头运动有起止与焦点。

### 4. R10–R12：把“极限”从公式变成可见边界

[同音乐对照 R12](boards/R12.jpg) · [连续帧](motion/R12.jpg)

参考 f988/1023/1059（41.188/42.646/44.146s）中，巨大的无穷轮廓占主要画域，两侧数字列持续累积；接近限制时出现明确边界。f970–981 显示正弦波到无穷形的切换，f1061–1072 则将大无穷形交给 AC/DC 的两侧对照。

我们现在的大部分面积仍是同一网格，细曲线和公式位于中间。建议保留 v3 已修好的两种握笔姿势和真实笔尖接点，先让圆周成为环绕她的空间轨道，再让正弦路延伸成跨越画幅的路径；到 LIMITATIONS，金线成为她主动停住的边界，人物视线也停在这里。文字可作为边界刻度或路径，而非再次在底部占一行大词。验收：无限扩展和停止是两个清楚的动作，金笔仍来自对方，不能变成她的控制器。

### 5. R13–R16：控件变化要传到画面内部

[同音乐对照 R13](boards/R13.jpg) · [连续帧](motion/R13.jpg) · [合并对照 R16](boards/R16.jpg) · [连续帧](motion/R16.jpg)

参考 f1081/1115/1149（45.063/46.479/47.896s）先让 AC 与 DC 的字形和波形分居两侧，再撤走此结构进入 VISION；f1347/1381/1414（56.146/57.563/58.938s）将 ME 与 YOU 两圈合为一圈。f1416–1427（59.021–59.479s）又从合圈转入并行通道。

我们的合圈已经表达了两人共享记忆，不需要推倒。更该补的是控制与空间之间的因果：AC/DC 切换后，同一条信号从来回流动变为单向抵达；关闭视觉后，让追踪目标先消失、空间只留下触碰位置，而不是仅遮黑面板。时间旅行让同一金笔拖过年代，把城市、文字和远近层以不同速度带走。合圈最后的交点接到下一镜的通信入口。验收：开关、信号、结果各有可观察的次序；不靠一个小开关标签解释整个动作。

### 6. R17–R22：给予要看得见接收端

[同音乐对照 R19](boards/R19.jpg) · [R21](boards/R21.jpg) · [R21 连续帧](motion/R21.jpg)

参考 59.5–62.5s 的通道有 ME 和 YOU 两端；刺激沿多条平行通路抵达，随后满足值增长。f1593–1604（66.396–66.854s）从 100 的收束画面直接切到占幅很大的字符心形，形成清晰的规模跃升；f1655（68.979s）心形开始散开并进入执行语义。

我们 R19 的客串卡列和 R21 的角色展示卡有各自意义，但主角的动作与“让你开心”之间仍隔着界面。建议保留客串设计，把它们作为侧方经过的选项，主焦点仍在一个真实正在完成的请求；输入线路抵达 ASTRA 掌心，再由她的一次明确动作生成世界中的结果。角色亮相可以由参数/字符在原画轮廓内完成，五官和结饰保持原画。验收：人物完成一个可辨认的动作；至少一次看见对方对结果作出独立新增，而不只是反馈条填满。

### 7. R23–R25：让“被困”逐层改变可活动空间

[同音乐对照 R23](boards/R23.jpg) · [连续帧](motion/R23.jpg)

参考 f1689/1718/1748（70.396/71.604/72.854s）里，嵌套框沿纵深排列，层数与计数增加；f1677–1688 可见中央 EXECUTION 退出，嵌套结构进入。稳定的外框没有被证明变形，压迫来自内部重复和占用。

我们从全景缩回一个窗口已建立了视角变化，可继续加一层有事件的空间关系：第一层限制笔迹，第二层挡住翼尖，第三层复制原路让出口回到原点。保留人物与城市连续坐标，避免每层只复制同一缩略图。R24 不必在不足一秒内塞入十二个同等重要的新物体；只让三次清楚的封闭动作先后完成，余下阵列作为后果。验收：每增加一层都失去一种具体自由，观众能看懂压缩发生在哪里。

### 8. R26–R29：保留已修好的剖面，补齐“献给你”的路径

[同音乐对照 R26](boards/R26.jpg) · [概览](overview/overview-08.jpg)

参考 f1799/1826/1854（74.975/76.104/77.271s）把物件放在一条明确通向 YOU 的传输线上，字符从物件向接收端流动。当前参考的低清缩图不足以确认每个字符的字面含义，但传输方向清楚。

我们修订后的果蔬切面更具体，也适合保留。现在右侧营养结构与左侧剖面之间还缺一条可跟踪的因果路径。建议种子/分子从真实切面依次离开，沿金紫共有线路进入右侧正在生长的对象；每到达一组，世界里对应的叶、灯、颜色增加一处。验收：有明确起点、途中、终点和接收后变化，避免果实、化学图、笔尖各自成为三个静态中心。
