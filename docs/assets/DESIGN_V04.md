## 制作方式

使用内置 ImageGen 修订人物与补绘，未使用 API/CLI 生图。第一次整体修订改善神情，但仍错误保留了编结中心；随后用 ImageGen 移除两处错误结饰，补全被遮挡的白发和腰带，保留链与流苏。生成底图原样保存为 `assets/astra/v04/standing-base.png`。

- [修订提示词](../../assets/astra/v04/prompt.txt)
- [去除错误结饰及补底提示词](../../assets/astra/v04/cleanup-prompt.txt)

精确图标使用项目已有的官方 Blossom 原始 path，制作白色、细暗边的原生 SVG 结饰，按头侧与腰间分别定位旋转。六边形中心和六环之间均为真正空隙，露出下方发丝／腰带；没有外圆、圆盘或底板。头侧的发丝轮廓会透过孔洞，因此局部线条比腰间更丰富。

最终立绘由本地原生 Canvas 审阅场景渲染：[渲染脚本](../../tools/render/render_standing_v04.mjs)。源 PNG 不覆盖；加载时清除 alpha<16 的近透明残点，使 alpha>=240 的墨色区域不透明，保留边缘抗锯齿。画布四边增加留白。完全透明像素的隐藏 RGB 清零，避免忽略 alpha 的查看器把这些颜色显示成灰雾。没有使用 Python 编辑图像；Python 核验脚本只读取成品并输出 JSON 数据。
