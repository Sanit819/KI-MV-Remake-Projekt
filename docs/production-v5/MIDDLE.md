## 最终画风与源图

采用用户最后确认的约束：原人设轻盈服装、紧凑柔和脸部轮廓、源图内绘制的无外圆镂空 GPT 结饰；普通动作保持深紫黑脸和刘海遮眼。黑脸不是 Canvas 覆盖贴片，而是每张完整源图通过 built-in ImageGen 单独局部编辑。中段的 v4 原有明确露脸例外 R50 继续使用 `v08/face-eye-v02.png`，没有把普通动作新增为露脸例外。

16 张最终路径为 `assets/astra/v09/Axx-xx-shadow.png`，同名 `.prompt.txt` 保存实际完整编辑提示词。`middle-assets.json` 保存每张原画的键、路径、源像素手/腕/笔尖/坐姿锚、动作组、阶段、ImageGen 实际输出路径以及原姿态生成路径；全部标为 `faceTreatment: shadow`、`styleRevision: 3`。原姿态生成提示词保存在不带 `-shadow` 的同名文件，亮脸版本没有删除。较早宽肩/长侧脸的 7 张未采用稿保留 `-style1` 后缀；两份 archive JSON 记录淘汰原因和完整原提示词。

绘图方法：每一姿态一次独立 built-in ImageGen 调用，后续阶段引用该组第一姿态以稳定角色、服装与机位。没有用改名、裁切、换色或透明手部模型增加新动作数量。第一次生成的16个姿态在用户补充黑脸约束后，各做了一次仅脸和前刘海的局部源图编辑。所有编辑结果逐张实看；尺寸与对应姿态源图 16/16 一致，原先单点检查 (10,10) 的 alpha 为 0，手、笔和坐姿锚未见位移。后续严格四角核验发现 A04_01 与 A05_03 的左下角 alpha 为 1，其余三角为 0；这两张四个角各 16×16 范围的最大 alpha 也只有 1。`Art.load` 明确忽略 alpha<16，因此生产输出中的这些角有效透明；保留原始文件，不把严格四角全零记成通过。原始 alpha 保留，交由统一 Art 三墨描边渲染。
