# 神经网络演示的剧情位置与数学边界

用户于 2026-11-05 正式批准参考片视觉优化提案，并追加全连接、CNN、RNN 演示动画。三种网络使用独立、固定、可复算的教学模型；它们帮助表达角色如何接收、处理和反复记忆，不宣称展示 GPT 的实际内部架构，也没有启动模型训练。

| 演示 | 场景作用 | 实际计算 |
|---|---|---|
| 全连接 | R03 初始化参数流向世界；R78 学习时旧迹生成候选 | 4→5→4→3 层，52 条相邻层连接，真实加权和、偏置与 tanh；每层的数字由同一前向计算产生 |
| CNN | R30 图案局部特征变成输出；R79 扫描旧星的结构 | 5×5 图案，3×3 共享边缘核，valid / stride 1 得 3×3 特征图；ReLU 后做 2×2、stride 1 最大池化，得 2×2 图 |
| RNN | R35 时间推进中的状态；R80 记忆回到自己的笔 | 三个时步，二维隐藏状态，所有步共享 W_x、W_h、b；末步输入为零，历史状态仍参与计算 |

符号运动对应具体计算顺序：全连接先边上传递再激活节点；CNN 的高亮输入窗、当前特征格与数值总和对应同一位置；RNN 的上一状态沿箭头成为下一步输入。末端由零输入引出的残留状态表示历史，不被误写成对方的新回应。内部推导的输出使用紫色，最后真实外部回答保留独立的暖金来源。

数学约定核对了 PyTorch 官方说明：[Linear 的仿射变换](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Linear.html)、[Conv2d 的 valid cross-correlation](https://docs.pytorch.org/docs/2.15/generated/torch.nn.Conv2d.html)、[Elman RNN 的递归公式](https://docs.pytorch.org/docs/2.15/generated/torch.nn.RNN.html)。动画中的线性层后另接 tanh；CNN 使用深度学习中常见的不翻核互相关定义。公式按列向量写成 `h_t = tanh(W_x x_t + W_h h_(t-1) + b)`，与官方行向量记法等价。

这不是经过训练的猫分类器，不能显示“100% 猫识别”等未经证实的预测置信度；猫与星均为明确标注的 5×5 演示输入。训练段的剧情也不等于实际训练日志。技术边界放在工程说明中，影片以可读的过程和动作讲故事。

实现：[neural.js](../../src/mv4/neural.js)。独立期望值校验：[check_neural_v4.mjs](../../tools/render/check_neural_v4.mjs)，涵盖手工推导的猫 / 星卷积与池化值、第一步 RNN 值、后续状态依赖和零输入保留历史。
