## 2. 制作单位、分层与动作密度

**一镜是一段行动，不是一张画。** 每镜至少登记：前态、决定／接触态、后态，主体锚点、道具状态、前景遮挡、镜头方向、进入／离开时的速度。没有人物的静观镜，也要有可见的空间变化，例如草弯下再回弹、影子掠过后停住；不强制增加无意义的摆动。

| 等级 | 使用范围 | 建议资产与运动 | 本片实施状态 |
| --- | --- | --- | --- |
| A：静观与余韵 | 土地、红花、空位、故土与托付之后 | 一张分层主景，2–3 个环境或表情状态；稳定停留可占多数时长。必要的花／布／草动作有独立层。 | 规划；现有四格图仅供构图参考。 |
| B：有限动作 | 日常、准备、受令、扣带、抬眼、递物 | 主行动通常 3–5 张完整关键姿态；手与道具按同一次动作联动。小幅关节运动只有在补全遮挡后的结构并检查后才使用 rig。 | 规划；不沿用彩色试片的运镜作为动作完成证明。 |
| C：连续行动 | 起飞、交战、受创、超负荷、主体分离 | 一段明确运动轨迹；通常 5–9 个关键姿态／机体视向，加必要中间态或受约束 rig。关键轮廓变化需新画／可核模型，不能由平面拉伸代替。 | 规划；机体画稿与对应角度仍须独立验收。 |

频率只描述**需要运动时的姿态或局部状态更新**。保持静止的表情、抓紧的手、余韵镜可以长停；以下均为待验证建议：

- 前段试用 4–6 pose-updates/s（60 fps 输出中每态约 10–15 帧），镜头与风可连续运动。
- 中段活动部分试用 8–12 pose-updates/s（约 5–8 输出帧一态），优先补动作转折，平静段仍保留停顿。
- 高潮的快速表演试用 12–20 pose-updates/s（约 3–5 输出帧一态），飞机轨迹、云与已验收的连续 rig 可按 60 fps 求值。临终托付不因位于后段而被迫加速。
- 优先试 5／6／10／12／15／20 等可整除 60 的节奏；8 次等节奏需明确曝光表。改变更新频率应跟随动作段落，不逐帧随音量跳变。

“5 张关键姿态”不等于“每秒 20 张不同姿态”。要达到后者，必须实际补中间态或让经过检查的 rig 在相应时刻产生不同的合理姿态。重复 3 张原画、整图缩放、光效或加倍编码帧数都不算提升身体动作密度。远景循环可复用，近景一次性动作不能倒放循环伪装。

建议层次从后到前为：纸面／远景、地景或远云、人物完整姿态或机体、相连道具与局部动作、前景遮挡、受控灰阶气氛、红花保色层、字幕。纸纹固定在画纸坐标或随所属层稳定移动，不每帧随机改变；铅笔线轻微更替使用固定种子与有限纹理态，不让飞机轮廓、面部或文字沸腾。

红色集中在银莲花，服装红缝线、机身金线等仍以灰阶明度与纹样保持身份，不自行扩成“全片每个重要物都发红光”。具体颜色范围可在样段统一检查。飞机只允许符合投影关系的刚体平移、等比缩放与画面内滚转；改变观察俯仰／偏航需相应视向画稿或有参考约束的模型。

## 4. 连续性的具体执行办法

**动作前、中、后不能只有名称。** 姿态表记录身体重心、肩／腕／接触点、眼线和道具方向；至少看一遍并列图确认肢长与衣饰一致。站立需脚底接地；坐姿固定座位与骨盆；抓握态的手和物件不能分别漂移。大幅转头要画侧面／转折态，不旋转一张正面头像。

**换姿态的位置由动作决定。** 在眨眼、转头经过侧面、袖子遮挡、舱框掠过、云覆盖等时刻换画，可减小轮廓跳跃；遮挡前后接触点、重心和速度仍必须连续。A→B 的整个人体不能半透明叠在一起产生四只手。遮挡不是缺几何的通行证，露出的部分仍须正确。

**跨镜保留同一个动作时钟。** 同一行动可能跨全景、舱内和特写，使用共同 `action_id`、绝对起点与轨迹；切镜只换相机。前镜末手抬到一半，下一镜从同一位置继续，不能重新抬手。空战相邻镜先检查机头朝向、相对位置、画面运动速度、尾迹和地平线倾角，再调切点。

**同向匹配与时空区分同时成立。** 001→002 可以同构图变季节；002→003、004→005 必须保留不同人物／地点。044 必须有任务分隔。047／050／053／060 的记忆可用纸白边缘、较缓运动和已出现构图回返，不能只凭淡入淡出让亡者看似重返当下。

**高潮增加的是运动信息。** 优先使 041–043 的分流、054–056 的分离机首追逐方向与速度连贯；减少毫无空间交代的碎切。高速段也保留行动开始与结束，镜头不逐切都从慢推重新加速。需要时用起止速度相接的样条；一次冲过后让尾迹继续，不能每个镜头统一套 `ease-in-out`。

**人物与机体独立维护身份。** Rex 遮面；Tewy 礼服／压力服分阶段；Toprak 银白发。F/A-18F 双座与 C 单座是不同资产；Kate M28 Rafale M 与 M29 本片 C 型之间经过 044。飞机可见结构、挂载、起落架、损伤均跟随状态，不因姿态替换而跳变。

## 5. 时间线与音乐的实现提案

建议新工程采用下列最小数据结构；这里是接口设计，不是已落地代码：

```json
{
  "shot_id": "HRA-049",
  "start_frame": null,
  "end_frame": null,
  "action_id": "moon11-overload-pass",
  "action_start_frame": null,
  "tier": "C",
  "pose_events": [],
  "anchors": ["cockpit_origin", "shoulder", "wrist"],
  "trajectory": null,
  "camera": null,
  "occluders": [],
  "music_events": [],
  "memory_state": "present_m29",
  "source_art_approved": false,
  "animation_verified": false
}
```

输出帧 `n` 的主时间为 `t=n/60`。镜头、共用行动、机体轨迹、相机、风和字幕均从该时间直接求值，随机质感固定种子；人物有限动画可在自身动作时钟量化，镜头与飞机位置无需随之抽帧。精确姿态接触事件仍落在明确输出帧，不依赖模糊的实时计时器。

预览以浏览器音频 `currentTime` 为主钟，画面只追随，不另开一个会漂移的音乐计时器。导出按整数帧离线求值再与原 FLAC 选段对齐；用户源曲仍是 48 kHz／16-bit 双声道，保持原文件与实际参数。这里没有第一企划的 5 秒前缀，不继承旧裁切量或旧 BPM。

音乐绑定分三层：已确认歌词／乐句锚点决定行动段落，人工挑选的重音决定接触或转折，频带瞬态候选仅辅助灰阶明暗／风／小幅镜头。先挑少量有意图的事件，留出宁静；不把每个频谱峰变成切镜、角色抽动或整屏闪白。歌词未对时的字段保持空，不用能量峰自动认证拉丁文唱词。

## 7. 样段完成后才可声称的结果

验收应给真实样段与结果记录，而非仅交接图或网页：

1. 所用姿态、机型与服装已实际并列看图；动作前／中／后均可辨，手指数量、肩腕连接、坐姿、脚底与道具接触无阻断。
2. 每次换姿态前后各检查数帧，必要时慢放；重点查跳位、复手、道具脱手、脸型／头盔变化与飞机翼面漂移。遮挡不能遮掉关键因果。
3. 任取同一帧直接跳转与顺序渲染，状态一致；相邻镜轨迹、眼线、滚转、速度与损伤状态连续，时空跳跃镜则清楚标记。
4. 24 秒样段实际播放和导出，核验 1440 帧／60fps、音视频起点与选段；直接试听与未试听的核验范围分别记录。不能从正音频解码字节推导艺术上的卡点已通过。
5. 报告实际采用的姿态更新率和独立姿态／rig 状态数量；区分人物动作、环境、相机、编码帧率。没有实施的 12–20 updates/s 或 60fps rig 继续标为目标。

后续把通过的动作单元方法扩到全片：本轮先完成花／Rex的30秒示范，再按结果选择本节045–049候选、014–016的起飞与出发、017–020／033的有与无、054–060的危机与托付。最后一组先补清分离机首可见几何与关键顺序，再连成动画；不能因为前一个样段通过而越过它的独立难点。
