## Export logic audit

- The full selection is `[0,3300)`, `[3300,6600)`, `[6600,9900)`, `[9900,13100)`: 55 + 55 + 55 + 53.333333333 seconds, 13,100 frames at 60 fps. Child outputs are video-only. Explicit concat durations carry no AAC priming or padding across a video boundary.
- The final mux reads the original audio exactly once with source start 0, encodes it once to AAC 192 kbit/s, and uses `apad` to 218.333333333 seconds. Original audio is neither looped nor stretched. The 6-second approved extension is measured from the original video grid endpoint 212.333333333, approximately 2.7 ms after the source's 212.330667-second endpoint.
- Actual read-only FFmpeg decoding compared this exact source with and without input `-ss 0.000000000`. At a 0.5–3.0 s window, measured lag was 0 samples at 24 kHz, correlation 0.999999999999969. The feared AAC zero-seek origin error was not reproduced. Source metadata is 48 kHz stereo AAC.
- Video verification scans every packet. It requires a 60,000-unit timescale, 13,100 distinct presentation times exactly `n*1000`, a 1000-unit duration for every packet, and strictly increasing decode times. Negative initial decode times caused by B-frames are deliberately allowed. It additionally reports the three concat boundaries.
- The audio reference is a fresh mono float PCM decode of the original plus only zero padding to the full duration. Distributed comparisons use 1, 31, 60, 90, 120, 150, 180 and 200 seconds, avoiding the silent ending. Source-start slicing is 0 for the full movie and the correct source quarter start for a single-part test.
- Tail verification independently decodes the added 212.333333333–218.333333333 interval and requires at least the expected duration minus one frame, RMS <= -80 dBFS and peak <= -65 dBFS. Full audio decoding also bounds total decoded duration to one video frame. At this 48 kHz source rate, normal AAC final-frame padding can be about 13.33 ms, within the deliberate 16.67 ms allowance.
- The full verifier independently decodes every video frame and the complete audio track, then checks dimensions, 60 fps, 13,100 decoded frames, duration, distributed audio lag <= one frame and correlation >= 0.98.

No definite logic error requiring intervention was found. Packet, decode, duration, correlation and silence checks still must pass on the completed file. These checks do not certify visual storytelling, lip/word timing or continuous motion quality.

## Create 1080p60 from the verified 4K master

Run after the master has completed and passed its checks, with the repository as the working directory. This scales video once with Lanczos and copies the master's AAC packets without encoding audio again. It does not re-run browser rendering. `passthrough` preserves the source frame times; no `-r`, duration trim or audio filter is applied.

```powershell
$mvRoot = 'D:/myskills/updream/KI-MV-Remake-Projekt'
$mvFfmpeg = Join-Path $mvRoot '.cache/python/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v9.0.2.exe'
$mvMaster = Join-Path $mvRoot 'exports/astra-world-execute-me-full-v2-4k60.mp4'
$mvPreview = Join-Path $mvRoot 'exports/astra-world-execute-me-full-v2-1080p60.mp4'
& $mvFfmpeg -hide_banner -y -i $mvMaster -map 0:v:0 -map 0:a:0 -vf 'scale=1920:1080:flags=lanczos:in_color_matrix=bt709:out_color_matrix=bt709:in_range=limited:out_range=limited,format=yuv420p' -fps_mode passthrough -c:v h264_nvenc -preset p6 -tune hq -rc vbr -cq 19 -b:v 0 -profile:v high -bf 2 -c:a copy -colorspace bt709 -color_primaries bt709 -color_trc bt709 -color_range tv -video_track_timescale 60000 -map_metadata 0 -metadata 'comment=ASTRA full MV v2; 1080p60 derived from verified 4K master; 13100 frames; master AAC copied without re-encoding; approved quiet extension=6s' -movflags +faststart $mvPreview
if ($LASTEXITCODE -ne 0) { throw '1080p60 conversion failed' }
& 'C:/Users/auscar/miniconda3/python.exe' (Join-Path $mvRoot 'tools/render/verify_full_mv.py') $mvPreview --width 1920 --height 1080 --fps 60 --frames 13100 --source-start 0 --ffmpeg $mvFfmpeg --audio (Join-Path $mvRoot '.cache/full-export-v2/3840x2160/all/complete/original-with-approved-silence.f32.wav') --out (Join-Path $mvRoot 'exports/astra-world-execute-me-full-v2-1080p60.full-verify.json')
if ($LASTEXITCODE -ne 0) { throw '1080p60 verification failed' }
```

Do not substitute the unpadded original as the `--audio` reference here: that would correctly fail the source-coverage check for the approved six-second tail. The padded reference above is generated by the completed master export and its hash is recorded in the master render report.

## Check that the derivative keeps the exact AAC payload

These two read-only commands hash the audio packet bytes rather than the whole MP4 container. The SHA256 values must match. Combined with the independent alignment/duration check above, this establishes preserved audio content and timing rather than merely matching codec labels.

```powershell
& $mvFfmpeg -hide_banner -loglevel error -i $mvMaster -map 0:a:0 -c:a copy -f hash -hash sha256 -
& $mvFfmpeg -hide_banner -loglevel error -i $mvPreview -map 0:a:0 -c:a copy -f hash -hash sha256 -
```

The derivative's quiet tail is the same encoded audio payload as the master if those hashes match. The master must first pass its dedicated silence measurement; a hash match alone cannot prove silence.
