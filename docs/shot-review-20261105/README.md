# 原作逐镜讨论室
日期：2026-11-05。用户要求逐帧分析原作构图，并为每个镜头附图讨论 ASTRA 的演法。

入口：[交互讨论室](index.html) · [87镜图文稿](SHOT_DISCUSSION.md)。每镜都有同音乐时点的三组对照帧、构图、运动、现片表现、原创提案和讨论点。使用 R00–R86 编号；R00为原作片头，R71–R77为用户截图所在高潮段。

## 实际完成范围
- 从原作当前场景定义取得87镜：86正片＋1片头；以源码镜号索引，结合实际编码帧检查，镜内动作不冒充新的镜头。
- 解码原片852×480、30fps的全部6509帧，并逐帧计算灰度/对比/边缘重心/帧差，用于定位变化。所有原片帧都可以在交互页逐帧查看。
- 解码本片1080p60播放版全部12740帧，预览均缩到640×360；没有插帧或用低清图推断4K细边质量。
- 实看87张六格对照板；前61镜的连续帧条全部检查，晚段检查14张连续帧条并重点复核高潮。逐镜记录622个不同的原片证据帧号；这是关键帧/局部连续帧审阅，**不是人工逐张看完6509帧或连续听审全片**。
- 每镜三组对照：上原片、下ASTRA v1。原片播放器时间减5秒片头，再加−0.0835093608秒对齐偏移，取本片最近60fps帧。原作源码镜头边界与歌词起句不总是同一时刻，不能用镜头起点冒充歌词首字。
- 原片末端约216.96播放器秒，对应本片约211.87歌曲秒；本片之后约0.46秒尾留白没有更晚的原片对应帧。
- 文件/帧号/完整性见 validation.json；无头浏览器桌面、移动布局、逐帧加减、镜头切换与图片加载见 browser-check.json。

## 讨论方式
打开 index.html，选择“先看高潮 R71–R77”或输入编号。每镜下方可以展开连续帧、歌词和本机笔记。逐帧窗口支持左右键、前后一帧、前后镜头与复制编号；原片一步1/30秒，本片跟随最近1/60秒源帧。
例如：R73，原片f5179，我希望她更靠近镜头，但保留胸口里的运行记录。笔记仅存本机，可导出JSON；没有自动发送或联网同步。

图中下排始终是已交付v1，新演法仍是文字提案。R61以后的提案已复核：计数与末副歌仍有控制冲动，LOVE后才自主撤回；末句译文完整保留，约208秒回应为待讨论剪辑候选，不将人工4秒字幕持留误认成声音。温暖共画不取消，不自动改动已确认的STORY/STORYBOARD。
