## 复现入口

本机需要 Node、`npm ci` 安装的 Three.js / Playwright、Edge、FFmpeg（NVENC）及带 NumPy / Pillow / OpenCV 的 Python。原完整 v5.2 音视频位于相邻归档目录；不随源码提交。相关路径见两个工具开头。

```powershell
npm run full:v6:4k
npm run full:v6:package
```

正文从0帧渲染至13100帧，60fps。四路覆盖[0,3275)、[3275,6550)、[6550,9825)、[9825,13100)，各自每600帧保存一段及逐帧状态；源码与数据指纹相同才可恢复。独立显卡执行Three.js及2D栅格，RGBA8经Blob送入编码器，不经有损中间图。合并给每段明确精确时长，避免容器毫秒取整造成PTS接缝。渲染中不得修改src/data或渲染工具。封装仅复用原片头警示300帧及完整音轨，最终13400帧、223.333333秒。

输出位于 `exports/mv6/final4k/`，由 Git 忽略。4K母版保留原192kHz双声道ALAC数据包；1080p60预览使用AAC320kbps，方便播放。

## 本次检查方法

独立静帧检查覆盖启动、旅行、双波形、压迫、六人收容、执行、神经网络、回应与结尾。4K尺寸另检查了原图透明合成、牢笼与文字。完整成片还需全程解码、13400帧整数PTS、源ALAC包身份、AAC波形对齐及每镜/每秒图板审查。

技术解码、计算一致性、视觉静帧抽查与用户审美验收是不同证据；本记录不声称连续观看或直接听音。

新增数值演示的本地记录：`exports/mv6/verification/inference-numerics.json`。同一430点合成轨迹，预热后420点的观测RMSE为0.0461373、滤波RMSE为0.0201240，协方差保持对称。该数字只检查当前动画用的小型模型。匹配代价由实际坐标计算，贪心为0.0705，匈牙利最优为0.0327；画面为清晰显示将成本乘100。

性能诊断与废弃试跑只保留在exports/mv6各检查目录；`final4k/`才是完整交付目标。无损RGBA方向与颜色已实际检查；小样只用于内部管线验证，不作为本次交付。

最终传输使用WebGL2的三个PBO缓冲异步读回与Blob上传，NVENC surfaces=24。五帧与同步RGBA管线的解码对照SSIM全部为1.0（记录于exports/mv6/transport-pbo/ssim.txt）；该对照只证明这五帧，完整成片另行验证。四分片以jobs=2限制同时渲染数，降低资源峰值。

持续渲染检查通过120帧（76.991秒含加载），使用每8帧显式回收Blob暂存缓冲，跨过此前ERR_BLOB_OUT_OF_MEMORY失败点。最终逐帧记录包含绘制/读回/上传耗时，最终进度不以试跑计数冒充。
