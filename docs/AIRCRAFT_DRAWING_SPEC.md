# 机体绘制规范：先核三视，再做镜头

2026-11-06。用户要求“搜集对应飞机资料，严格按照三视图绘画”。本规范适用于分镜中每一架可识别的飞机、座舱和 X-40 分离机首。当前完成的是资料收集、分镜和绘制约束；没有机体线稿通过验收，也没有声称已经绘成原画。

## 对应的含义

三视图必须同时说明 **型号、子型号／版本、俯视、侧视、前视**。同一型号不同版本、原型与量产、单座与双座，均不能默认共用。前后三视之外的透视截图可以补涂装与可见细节，但不能冒充正投影，也不能从一张斜视图等比拉伸出所谓“三视”。

资料来源与已保存文件见[参考档案](../references/aircraft/README.md)。每份资料记录实际描绘的型号、来源 URL、页码／实录时间、作者与许可、取得日期、文件 SHA256 及缺口。制造商尺寸、模拟器说明图、模型水贴定位图、社区重绘与游戏截图各保留自己的来源等级。

## 绘制流程

1. **锁定资产。**先确认人物、所属单位、故事阶段、准确子型号、涂装和受损状态，再给资产版本号。X-40 完整机体与分离机首是两个资产；F/A-18C、E、F 分开。
2. **验收参考。**顶／侧／前是否齐全；是否真的同一版本；原图是否裁切、透视或镜像；三图轴线、机长、翼展、高度能否相互解释。只有照片或原型近似图时，状态仍是待补。
3. **建立基础线稿。**参考原件不改写。另建工作副本，标记机鼻、座舱、翼根、翼尖、尾喷口、垂尾与平尾等锚点。三视使用统一比例尺，不能为“看着顺眼”分别拉长、压扁。
4. **核对关键结构。**分别检查座位数、座舱罩位置、进气口形状及间距、鸭翼有无、翼面前后掠与折线、尾翼数量与倾角、发动机喷口、舰载折叠结构与起落架。没有证据的腹部结构保持未定，不自由补全。
5. **建立镜头透视。**先由已核准三视构建受约束的简单三维体块／可投影线稿，再固定相机角度、焦距、机体姿态；最终绘画沿投影检查遮挡与缩短关系。不能把顶视平面旋转成透视飞机。
6. **补游戏外观。**在几何基础上应用 AC8 的机身号、金线、队徽、色块、挂载和损伤。真实飞机三视不证明游戏涂装；游戏涂装也不能改掉机体结构。禁止镜像 022／011 与单位徽记。
7. **验收到镜头。**每个姿态保存线稿／参考叠图；核对相邻镜头的翼面、挂载和损伤一致。上色、光照或动态模糊不能用来掩盖错误轮廓。

如果后续使用生成工具，只把它用于受参考约束的画面制作；“提示词写了准确型号”不等于符合三视。生成结果须回到同一组锚点与投影检查，错误时修正或重绘，不能因为画面漂亮而通过。

## 验收记录至少包含

| 项目 | 应保存的证据 |
| --- | --- |
| 来源锁定 | 资料 ID、实际型号、版本、三视是否齐全；原件 SHA。 |
| 比例 | 使用哪个尺寸／标尺；机长、翼展、高度是否同尺度；没有可靠尺寸时明确只做图内比例，不编造米数。 |
| 锚点 | 鼻尖、座舱、翼根／翼尖、垂尾／平尾、进气口／喷口的三视位置。 |
| 相机 | 镜头 ID、相机位置／投影方式、姿态与使用的基础线稿版本。 |
| 差异 | 叠图及逐项偏差；如果设数值阈值，写明那是本项目绘图标准，而非航空工程精度认证。 |
| 连续性 | 人物、机号、阶段配机、挂载、起落架／襟翼状态、损伤阶段。 |
| 结果 | `参考待补`／`线稿待审`／`几何通过`／`镜头通过`，不以一个“完成”混淆全部步骤。 |

## 当前核心缺口的处理

- **Su-57／022：**现有早期 T-50 三视只能作为对照资料，未证明与量产 Su-57 或 AC8 机模一致。游戏展示图与 022 实录负责校对可见形体与涂装。需要补齐或经同一版本多角度核验的三视，才能批准外形。
- **X-40：**现有官方／实录检索尚未取得可靠正投影三视。完整机体和分离机首分别有透视参考；先据已见镜头排构图，几何待补。不得用 FA-36、X-36、Su-57 或其他虚构飞机拼接代替。
- **F/A-18C／F：**单座 C 与双座 F 的整体机体不同，必须分开来源与基础线稿；带“F-18”泛称的图不能自动验收为两型通用。
- **Rafale M：**B 型双座三视不能直接充当 M 型；C／M 差异与舰载细节另核。若只有机翼相似的通用图，仍保留型号缺口。

这些缺口限制的是机体定稿，不影响已经完成的剧情、构图和人物关系设计。后续搜集资料仍沿用同一清单追加，不回写原记录伪装成早已齐全。
