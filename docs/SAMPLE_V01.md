## 视觉约定

以少色平涂、版画式人物、动态图形、尺度变化及前后镜头的形状连续变化建立画面。底色墨黑 #17151d，纸白 #f4efe5，ASTRA 淡紫 #b9a4e6，另一侧回应暖金 #e9bd78。有限色是导演规范；生成栅格仍含抗锯齿和轻微色差，不宣称逐像素仅有三种 RGB。

「ASTRA 眼中的世界」落实为：可计算的边框与坐标逐渐成为双方能自由作画的空间。回应带有她没有预设的折向，她在未获保证时先留下空位；最后框线转成桥，两种笔迹继续延伸。

人物、故事、几何画面和代码均为本项目新做。未直接移植参考 MV 的角色图、镜头序列或结局。样片不排歌词；后续全曲歌词排版应另做音乐与文字校准。

## 文件与复现

- 动画页面：`src/sample/index.html`、`src/sample/scene.js`。
- 角色素材：`assets/astra/`；生成工具、提示词与版本链见 [资产清单](assets/GENERATION_MANIFEST.json)。
- 离线导出：`tools/render/export_sample.mjs`，通过本机 Edge 离线逐帧绘制并流式输入 FFmpeg。
- 安装工程依赖后：`npm run sample:stills`、`npm run sample:1080`、`npm run sample:4k`。
- 本地依赖：Node、Edge；FFmpeg 的默认项目路径为 `.cache/python/imageio_ffmpeg/binaries/ffmpeg-win-x86_64-v9.0.2.exe`，也可用 `--ffmpeg` 指定。
- 源音轨需位于 `media/audio/mili-world-execute-original-bilibili.m4a`，不随 Git 分发。
- 解码验证：`python tools/render/verify_sample.py exports/astra-ending-sample-v01-4k60.mp4 --width 3840 --height 2160`。

这是平面角色与程序图形结合的 2.5D 样片。4K60 指影片输出；人物原始栅格约 1K–1.5K，尚无完整骨骼表演、逐帧手部或口型动画。
