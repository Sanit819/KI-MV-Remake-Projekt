# v2 人物、时间与机体连续性

2026-11-06。对应 [66 镜分镜](STORYBOARD_V2.md)。用户新指示允许两侧交替作为主体，本版取消 v1 的 Rex 独占主角限制。Rex 的身份承接与最终受托仍是重要线索；Tewy 的记忆、Toprak 的行动及 Joker 同伴的生活不必经由 Rex 讲述。

## 视角与关系

| 主体 | 可以独立呈现 | 不由镜头擅自推定 |
| --- | --- | --- |
| 索托亚离乡者／Cope 往事 | 故土、迁徙、生活空间的失去。 | 所有索托亚人物都是游牧出身；未经确认的迁徙灾害原因。 |
| Tewy | 红花与 Cope 的旧识、故乡、同袍记忆、身体代价、主动选择及最后托付。 | Cope 的恋人／共同童年家庭；失去自动免除其危害平民的责任。 |
| Toprak／Shadow 22／Ares | 对 Tewy 的忠诚、专业协作、追击“飞翼”、主动阻截及残酷行为的后果。 | 温和的反战英雄、被迫替 Tewy 赴死、未经原作确认的临终悔悟。 |
| Joker | Baxter 与 Tasha 的相处，Coster 的音乐与接替，Kate 的归来，以及彼此支撑。 | 队员只在 Rex 成长需要时才存在；未经确认的恋情。 |
| Rex | 后座生还、继承名号、实际承担责任、记忆与最后受托。 | 他能看见所有敌方私密往事；他在早期后座驾驶主机；他救活 Tewy。 |
| 两侧普通人 | 流离、庇护、共同生活与需要保护的空间。 | 索托亚进攻与 FCU 受侵略的责任可因相似生活而互相抵销。 |

红花、手、空位的匹配剪辑只建立观众理解中的联系，不额外制造人物会面、遥感、实际复活或空间穿越。

以下把已经核对的关系与本片选择的视觉连续性分开。玩家可换装的机体没有被写成唯一官方座机。

| 阶段 | 人物与位置 | 本片拟采用的机体 | 依据及限制 |
| --- | --- | --- | --- |
| Cope 生前 | Cope 前座，Rex 后座，两人共乘 Joker 1；Baxter 2、Tasha 3、Coster 4。 | Cope／Rex：**F/A-18F**；其余三机：**F/A-18C**。 | 双座 F 型有社区游戏记录与官方双人职责描述支持；僚机 C 型为本片统一选择，待具体过场近景再核涂装与挂载。四架飞机共五人，不是五架。 |
| Cope 牺牲后、Baxter 生前 | Rex 1、Baxter 2、Tasha 3、Coster 4。 | 四架 **F/A-18C**。 | Rex 接过机号与称号，不是在同一架沉没 F 型上凭空变成单座；场间过渡明确。 |

| M29 | Rex 1、Coster 2、Tasha 3、Kate 4。 | 本片选用四架 **F/A-18C**。 | M28 与 M29 是不同任务；用章节转场建立阶段变化。没有证据时不补画某基地的换装过程，不声称官方唯一配置。若后续决定采用原录像配置，须一次性更新该阶段全部镜头。 |

| Moon 11／M29 主体交战 | Tewy＝Moon 11。 | **X-40** 完整机体；可见 011 标号需按对应近景核对。 | 完整名称 Nightmare 的来源层级沿用研究表。完整状态与受损状态另存，不自由设计变形。 |
| M29 主体破坏之后 | Tewy 所在分离部分仍上传，Rex 必须继续阻止。 | **X40_NOSE** 独立资产。 | 不能继续画完整 X-40，不能把残骸、火焰当正常几何。独立资料目前缺正投影。 |

### M28 选用的辅助机型

- Green：F-16C；Flying Mole：F-4E；Shark：F-15C；Shilage 志愿队：Su-33；萨维亚佣兵：Rafale M。配属依据见[机型对应表](../references/SQUADRON_AIRCRAFT.md)。
- HRA-039 将部分援军镜头列为可合并，不必在短曲内逐队点名。仍然绘入画面的每架飞机，都须使用该型号的审核参考，远景不等于可以换错轮廓。
- MiG-29A、Su-35S、FA-36 等纳入资料库备用，本版没有为展示机型而增加剧情镜头。F/A-18E 亦是备用，不与 C／F 混画。
- Magnolia 可由原场景声画关系理解，但本版没有新增 E-767 外部特写，暂不为它增加独立制作需求。

## 时序与记忆标记

1. 前段索托亚故土与 Tewy 红花均为独立往事，不是 Rex 亲眼经历的闪回。视觉上通过地点、光线和重复物件建立往事关系，避免只靠字幕说明。
2. Cope 的牺牲先于 Rex 接任；Baxter 的牺牲先于 Coster 接替二号；Kate 归来在 M28。
3. M28 收束 Toprak 对决，M29 才是 X-40／Moon 11 对决。两任务之间必须有时间／章节的分隔感；不把选机变化画成同一航段内发生。
4. M29 关键顺序固定：危害城区的计划 → 解除保护与越限 → 主机被击毁 → 分离机首仍上传 → Rex 继续阻止 → 临终托付 → Cope／红花回忆 → 轨道打击落在恩索特区。
5. 后门线索、证据公开与战役结束属于后续收束；不能放到 Moon 11 尚在交战前，也不能声称 M29 是全部战役最后任务。
6. 白色浅盆中的红花回忆与战后身份牌旁的花是两套场景资产。片尾草地只表达局部生命继续，不宣称整个索托亚瞬间复绿。

## 绘制与镜头联动检查

- 出现机体的镜头都在 JSON 标记 `orthographic_required=true`；这只是需求标记，不代表已满足三视图验收。
- 单座 C、双座 F 的座舱、机身比例、进气道、翼面不能只改座舱罩而沿用同一张底图。座舱内景同样按机型参考，不能靠“外部机体不入镜”绕过校准。
- 飞行中起落架、襟翼、折叠翼、挂载、损伤与视线方向须连续。武器细节尚未核实的镜头保留动作层级，不能随意补出发射画面。
- 任何镜头替换机型，都同步修改人物阶段表、结构化分镜和参考图版本；原始核对材料保留，不反向改成支持新选择。
