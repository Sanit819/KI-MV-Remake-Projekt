# 《太陽系デスコ》逐帧研究 · 第三企划起点

日期：2026-11-07。分支：`太陽系デスコ`。参考：[用户指定 B 站 MV](https://www.bilibili.com/video/BV1UfZ2YwEP5/)。[打开本地逐帧查看器](../index.html)。

这支 MV 的核心是：**用辨识度很高的双人姿态循环作稳定主体，让文字、停顿、周边小角色与少量特效负责不断改变画面强度。** 它的大部分段落保持同一画幅和角色站位，动作可以长时间保持，也可以突然换姿；文字本身承担了大量动画和分段工作。第三企划最值得学习的是这些变化如何分配，而不是把所有画面都补成匀速的连续运动。

## 美术、构图与文字

底色是珊瑚红，开场解码帧像素约为`#FD5354`；这只是平台转码和JPEG后的样本，不是取得了作者原始色值。人物白色填充、细深色线，文字则极粗、近黑。强烈的线粗和面积差，让角色与文字即使交叠仍容易区分。末段会主动打破这套色彩规则，不能概括成全片绝无配色变化。

两位触角角色保持裙装在左、裤装在右，面对观众，小腿或脚部经常被下沿裁切。不能因为歌唱署名是初音未来，就把画面中的双人自行命名为初音或其他人物。稳定阶段几乎没有环境场景或透视变化；开场的上移属于画面内可见位移，不能凭成片进一步认定摄影机或图层软件的实现。

文字有五种主要作用：顶部与底部逐组累积、超大短词强调、前景标题覆盖、中央小句留白，以及多行重复构成纹理。多数大字被人物遮住；曲名、署名和部分中央短句会遮住人物。**前后遮挡关系也是节奏工具。** 如果改作中只保留底部字幕，会丢掉原片最主要的画面变化来源。

例如f1762–1773的超大前景短词仅12帧，随后文字回到人物后面；f3778–3873的中央前景句则停留96帧。它们不仅字号不同，阅读时间也不同。密集画面和突然清空互相支撑，不能把无字段误认为缺内容而全部填满。

## 动作如何成立

可以清楚辨认两种斜上指天的完整姿态、双掌分开靠近脸、合掌配短线，以及单角色双手肩侧的变体。左右指天会同时改变躯干倾向和腿部形状，中央两人的左右位置不交换；因此不宜把它理解为只旋转一根手臂，或整屏简单镜像。

f622、634、646、658显示局部每12帧换姿。更完整的f2734、2746、2758……2914，共16个换姿点，相邻均为12帧／0.4秒，同向往返24帧／0.8秒。这个周期是明确的**视觉证据**；是否每一次都落在实际音乐重拍上，仍没有耳听标注证明。

很多段落维持举手让文字先变化，在句组附近插入脸侧双掌和合掌短线；小角色进出与这些动作组合，让观众读到一个明确的视觉事件。f3016后的左角色单独动作、f3153附近开始的滚动小角色，又为双人同步规则制造例外。

全帧指标中，6095对相邻帧有4097对在213×120灰阶图上的平均差值不超过0.05，约67.2%。这个结果支持“存在大量近似保持画面”，但阈值受压缩、细线和文字影响；**不能据此把剩下1998次变化称为1998张原画或1998个镜头**。后段光点逐帧移动也会使差值上升，即使人物没换姿。

## 给第三企划的制作方法参考

先建立一套能重复使用的**完整姿态词汇与保持时长表**，再安排文字排版和少量例外。建议研究的动作单元包括双向指天、分掌/合掌、单角色肩侧双手；文字单元包括上下累积、中央留白、超大强调与文字墙；特殊单元包括边缘Q版进出、后方滚动角色与后段光效。这里是可见结构的整理，不是原工程素材清单或已经批准的第三企划分镜。

如果后续希望比原作更连贯，最适合补的是入场、拍手衔接与短促特效的动势；大段明确保持和突然换姿本身就是设计的一部分。提高输出帧率、平均给每处加过渡，会改变这些停顿的力度。角色主题、原创画稿、正式输出规格和是否保留这种跳变节奏，留待第三企划具体创作指示，不自动套入第一或第二企划的规格。
