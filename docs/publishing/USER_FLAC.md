用户 FLAC 自身最后 **0.5 秒并非严格静音**：RMS **-69.7594 dBFS**、峰值 **-52.3603 dBFS**。不将它笼统称作无声，也不额外切掉。可完整保留 FLAC 末端，再补零至原时间轴终点，并另保留已确认的 6 秒安静共画；对齐后的源文件结束到 218.333333 秒共需 **6.484458333 秒**零填充。这里的额外约 0.484 秒用于补齐原来已经无声的源尾，不是偷偷缩短音乐。

## 频谱观察不能代替来源证明

对源文件 30–38、90–98、150–158 秒三个 8 秒立体声窗口，在原生 192 kHz 下作 Hann 32768 点、50% 重叠的功率统计。24–48 kHz 频带能量相对 0–20 kHz 分别约 -52.69、-57.23、-63.84 dB；48–96 kHz 分别约 -62.20、-69.21、-74.02 dB。高频能量弱，但非全零。

此测量只描述能量分布。弱超声频带、频谱边界、99.99% 能量累计频点，都不能单独证明有损转码或升采样；尤其累计能量频点不是硬截止频率。本次没有把频谱形状判成来源“真/假”的证据。
