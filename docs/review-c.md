## 本段的画面组织

主体始终是红色平面背景、白色填充与细黑线的双人：裙装短发角色在左，裤装短发角色在右，均有触角形头部装饰。本段几乎不依赖更换场景，而是依赖**主体姿态替换、文字规模与位置变化、周边 Q 版角色、闪光层**来增加事件密度。

人物在本段至少有三种可区分的画面姿态：手指朝画面右上、手指朝画面左上、双手收在脸旁。左右指天状态会改变身体倾斜与腿部方向，女左男右位置仍保持，不能称整幅画面左右翻转。逐帧中有长时间保持，然后直接换姿态的情况；没有可见的完整连续肢体插值。是否由镜像、重画或裁剪拼接实现，原成片不能单独证明。

文字不是固定底部字幕：可从上方逐步追加到下方，成为占据大部分背景的巨字；可横向运动并带模糊；也会缩为居中短句。部分巨字被白色人物遮住，片尾标题和感谢字则明显覆盖人物躯干，遮挡顺序随用途变化。

## 循环与第三企划可借鉴之处

- 本段的鲜明节奏来自“保持—替换”的清晰姿态：在已核局部区间，一次换态间隔12帧，回到同朝向约24帧/0.8秒。容器30fps不表示每秒30张独立人物原画。
- 固定双人的位置与比例，使大字、四角 Q 版和光效能不断变化，而观众始终有稳定的识别锚点。
- 周边 Q 版先用模糊快速进入，随后清晰保持、摆动，再模糊退出；主角收手到脸旁是这一母题的视觉标记。可以借鉴这种“同一姿态指示同一种效果”的一致性。
- 182–195秒主要靠文字层数和光效提升密度；并没有必要为每个瞬态都换一张完整人物画。
- 片尾逐步撤去标题、感谢字，最终回到单纯双人姿态，与前面的密集画面形成收束。若第三企划采用此方法，应保留实际停留时长，而不是只截最后一张图。
