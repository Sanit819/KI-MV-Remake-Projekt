# 独立审核：稀疏镜头的场景补光

原三段光感与节奏已获用户认可。后来用户希望整片更明亮、更有未来科技感，因此本轮在独立 `src/mv52review/extra-light.js` 加上按镜头位置设计的线路/边缘；新增效果仍待用户审核，不能继承此前认可。原 `src/mv52` 光感模块与正式片未改。

## 接口与保护

`applyExtraLight(ctx,e,lighting)` 在原 `lighting.apply(ctx)` 之后、字幕前调用。`?extraLight=0` 立即返回零绘制。补光层匹配原相机矩阵，最后裁切到设计 y<933，人物蒙版在辉光之后扣除。

R31 的人物有 .42 透明度，直接用半透明蒙版会透进额外光线。当前临时光蒙版先按非零轮廓二值化、扩大一个 960px 蒙版像素再放大，保护其抗锯齿边缘；不改变原人物 PNG 或生产图形。R14 另明确扣除原感知遮罩内部。所有光点随已有动作进度单次移动，不另造循环闪烁或节拍。

最终模块 SHA256：`0202e43e3037f21e71bd61f3cc4bf6df895f0063808921e06c177d6b8a454cec`。
