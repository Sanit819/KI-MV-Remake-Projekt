# v5.2 全 86 镜光感覆盖审查

用户已明确认可本轮光感与节奏。本记录检查它在全曲的覆盖与实际作用边界；没有修改已认可模块，没有导出或接入正式全片。

本表统计原已认可光感模块的基线。后来新增的 12 镜场景补光单列于 [EXTRA_LIGHT_REVIEW.md](EXTRA_LIGHT_REVIEW.md)，不混入本表既有提亮域数值。

## 结论与口径

- `main.js` 每镜统一调用 `begin → camera → scene → apply → subtitle`，`lighting=1` 时覆盖全部 86 镜、17 连续段。现存运行证据为每镜首/中/末前一帧，共 258 个 4K 样本；不是只对三段短片起效。默认参数仍关闭光照，审核入口必须显式开启。
- 全部镜头共享紫金空间光池、亮部提取和三尺度辉光。普通人物增加细外沿，并由人物/深墨蒙版保护内部。光池是固定画面位置的宽渐变，不是每镜新增灯具或电路；可见技术空间主要来自现有场景自身。
- 下面“提亮域”是亮部提取蒙版的像素比例，尚未做辉光和合成，包含人物原色；不是最终亮度、前后改善百分比或独立光源个数。不能据此判定全镜明亮，也不能把低值自动判为失败。
- 三个样本的提取占比始终低于 1% 的镜头共 14 个：R02, R04, R05, R06, R08, R09, R14, R25, R31, R39, R44, R47, R50, R52。这些镜头应优先检查已有线条与空间光是否足以回应“全 MV 光亮科技感”。
- R48 碎片化人物走 `mosaicRaster → ctx.drawImage`，绕过 `lighting.artwork`：运行记录人物蒙版数为 0。该镜没有新增人物外沿与专属遮光蒙版；低饱和灰图使辉光提取少，但不能写成所有人物都获相同保护。R50 与 R86 表情窗有蒙版，portrait 按设计不画外沿。
- 等待、呼吸、回复、尾声动态强度为 0，静态空间光仍在。保留已认可的节奏；如果后续增加装饰光线，应评审空间与亮源存在感，不擅自加节拍或改变模块。
