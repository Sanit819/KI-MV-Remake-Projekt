# v09：最终版 v5 动作原画

当前生产仅以 [manifest.json](manifest.json) 激活路径为准：21 组、52 张新完整姿态全部已用于最终成片，所有新普通动作均为原画直接绘出的黑脸 / 刘海遮眼。最终版本于 2026-11-05 完成；[完整交付](../../../docs/FULL_MV_V5.md)和[脸部规范](../../../docs/production-v5/FACE_POLICY.md)记录例外与验证范围。

## 画风与生成方式

紫黑剪纸、三墨轮廓与原人设的紧凑比例。GPT 镂空六环结饰直接绘入人物原画，没有外圆框、圆形底盘或后贴的 logo 层；手臂、手、笔与身体一起生成，不能拼接独立手模。仅界面中的图标可使用独立 SVG。

全部新姿态使用内置 ImageGen 生成或编辑，源输出路径、实际提示词路径和人工查看记录存于各条 `provenance`；此前生成步骤保存在 `previousProvenance` 等字段及同目录文件。每个激活姿态有独立源图与独立 SHA256，没有用改名或裁剪同一张图凑数。提示词为对应的 `*.prompt.txt`，以清单中的路径为准；早段激活图名为 `*-inkface.png`，中晚段为 `*-shadow.png`。

被否定的最初 A10 侧脸、亮脸 style2 及其他中间稿保留以追溯修改，不参与当前成片。查看整个文件夹会看到历史亮脸图，不能据此判断最终选图；请从 manifest 追到生产文件。

## 脸部例外与透明边缘

52 张新动作均为 `faceTreatment: shadow`、`styleRevision: 3`。只有继承 v4 的眼部和认出回应近景可露脸：R50、R70–71、R86 正片 209.18–211 秒。共画普通镜头仍用黑脸；R21 的剪影展开不属于露脸例外。

源 PNG 保留真实 alpha。A04_01 与 A05_03 的一个角有 alpha=1，16×16 角区最大也为 1；生产描摹使用原有 alpha<16 清除阈值，所以生产边缘检查通过，但不能说这两张原文件所有角点均严格为零。原图没有为了美化报告而被改写。[原画检查](../../../docs/validation/astra-v5-artwork-inventory.json)保存源数据与有效阈值。

最终 79 个加载素材含继承的 v4 局部与六位客串；实际用到 65 个，其中新动作 52 个全部出现。最高三张源图的联合角色提交帧占比 16.48%；同图的移动、缩放、裁剪、换色仍按复用计算。详见[审计](../../../docs/validation/astra-v5-reuse-audit.json)。
