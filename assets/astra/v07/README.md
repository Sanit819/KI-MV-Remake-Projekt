## 三墨轮廓与透明边缘

当前流程由 [art.js](D:/myskills/updream/KI-MV-Remake-Projekt/src/mv2/art.js) 和 [trace.js](D:/myskills/updream/KI-MV-Remake-Projekt/src/full/vendor/trace.js) 实现，源 PNG 本身不被改写：

1. 读取 RGBA；**alpha < 16 的像素不进入墨版**。所有 16 个激活新图经实际通道检查均为 RGBA，均含 alpha=0 区域，是真实透明背景。各图另有 11,327–67,380 个 alpha 1–15 的低透明像素（例如 male 67,380、cat 16,562、foot 11,327），因此不能称原文件完全无低 alpha 残点。
2. 以 Y=0.2126R+0.7152G+0.0722B 构造三张覆盖场：alpha；alpha×clamp((Y−65)/16)；alpha×clamp((Y−125)/22)。自动 source bounds 使用 alpha≥128 的支撑区域，显式 bounds 可覆盖该值。
3. 覆盖场经过横、纵各一次 [1,2,1]/4 平滑；marching squares 以 127.5 为等值线。轮廓简化 eps=0.65、最小面积 5px²，再把平滑曲线组装成 Path2D。
4. 用 evenodd 填充三墨：#15101d、#614187、#b88ce8；灰态对应 #15101d、#51465f、#b3a6c1。孔洞/负形按路径保留。
5. 放大比例 >1.1 时直接画路径，较小比例使用预绘 canvas；代码纹理只投在角色暗部 mask 内。此流程能统一墨色并过滤低 alpha，**不会证明结饰拓扑正确，也不会自动修复错误人体**。

透明边缘的实际判断以合成帧为准。原图查看器显示的低 alpha 杂色和最终阈值轮廓不是同一结果；面积过滤也不是对所有孤立碎片的自动清洁保证。

## 图标与验收边界

角色的 GPT 结饰只来自对应 `*-knot.png`，必须是六瓣交织镂空、无额外外圆或底板。禁止在角色图上另贴 `interface-openai.svg`、Canvas logo 或圆形徽章。

[interface-openai.svg](D:/myskills/updream/KI-MV-Remake-Projekt/assets/astra/v07/interface-openai.svg) 仅供 ChatGPT 工作空间 UI 与 CLI 点阵使用；它和人物结饰是不同用途。样式一致、真实透明、素材可加载不等于逐像素结饰或所有人体透视认证。源图和合成帧的具体复核范围、已修问题与未验证边界统一记录于 [VISUAL_QA.md](D:/myskills/updream/KI-MV-Remake-Projekt/docs/production-v2/VISUAL_QA.md)。
