# 当前画风：铅笔灰阶与红花留色

2026-11-06 更新。用户已采纳 `storyboard/drawings-v1/` 的铅笔灰阶＋红花留色，要求画面像第一企划的伪动画一样连贯，并让高潮动作更流畅。下述为当前主用语言；后半部分保留彩色候选研究，不把旧候选当作用户最终选择。第一企划冻结内容不变。

## 当前制作语言

> 原创叙事动画画面，16:9。铅笔灰阶、清楚且有轻重变化的轮廓、稳定纸面质感，以疏密排线与灰阶块面建立体积；保留大片留白和可读空间，不使用照片皮肤、三维塑料材质或满屏颗粒。红银莲花作为集中保留的颜色，白色浅盆与环境保持灰阶。人物服装、装备、脸型和可见细节依据对应阶段的官方参考；Rex保持头盔、面罩或其他已核遮面边界。为同一行动分别准备前态、作用态、后态，统一肩、腕、接触物和视线位置；人物、道具、环境和前景可分层，任何分层都保留合理的结构连接。

红花留色不要求每镜出现花，也不把所有红色服装细节、警示和武器都改成发光焦点。官方服装的彩色标识在灰阶里保留形状与明度关系；压力袖缝线和腕扣等身份依据仍需清楚。已有四格图供风格与构图参考，不代表其机体几何已经通过。

伪动画以动作结果推动：手抬起并停下、头转向目标、风压低花瓣再回弹，层间速度服务空间。纸纹不每帧随机闪变；人物轮廓和机体翼面不靠扭曲漂移制造运动。动作分级与连续性规则见 [PSEUDO_ANIMATION_V2.md](../../docs/PSEUDO_ANIMATION_V2.md)。

**本轮实际样段已完成：** [motion-tests/v2](../../motion-tests/v2/index.html)，使用用户原曲72.5–102.5秒的连续30秒，从花的分层风动过渡到Rex三态头部动作（图集D排除）、独立云层，并增强后段运动连续性。本轮只使用A/B/C三态，D因面罩与管线跳变排除；720p完整动态预览、接点慢放复查、4K导出与两种封装的完整解码已通过。伪动画文档中的24秒终战方案是后续候选，本轮不按该方案执行。

### 彩色候选提示词骨架（非当前主用）

> 原创日系叙事插画，16:9 完整场景。细而有变化的彩色轮廓线，清楚的赛璐璐明暗块面与局部厚涂过渡；面部、手部和服装接缝细致，远景适当概括。深蓝、青灰或紫灰为主，金色边光与一处红色焦点。前景曲线、中景人物、远景光口组成环绕或斜向构图，视线沿衣纹、烟云、枝条或舰内结构自然移动。保留官方人物的脸型、发色、发型、服装与装备，不以幻想饰物代替原设定；不使用照片皮肤或三维材质的微噪点。

场面必须具体指定人物阶段和动作，再选一种构图，不能把以上元素全部塞入每一镜。银莲花、云带、舰舱弧线等属于已有叙事元素的视觉组织，不能因此新增真实会面、恋情或复活。

| 参考中的通用特征 | 本企划的应用 |
|---|---|
| 弯曲枝干／发束／衣褶围合主体 | 舰舱窗框和管线；记忆中的枝条；终战层云 |
| 主体局部高密度细节 | 官方脸部特征、手套接缝、衣领和徽记 |
| 冷底色与集中暖光 | 青灰故土与红花；舰上晨光；深蓝云层与白袖红线 |
| 人物与场景互相嵌合 | 视线指向花，手指指向书页，抬手方向引向天空 |

不沿用透明 PNG 边缘的异常像素、裁切背景或黑色空洞作为美术效果。全片需要横向电影画面，参考的方形卡面密度只在局部使用。

## 制作目标与已完成的彩色试验

最终目标按用户要求登记为 **Hi-Res／3840×2160／60 fps**。已完成的彩色v1是插画加轻微运镜的风格试听，人物没有逐帧动画。生成原画按实际像素记录，再放大到4K视频；不能称原生4K绘制。灰阶v2已完成30秒分层动作示范，具体见上方当前记录；原始音乐是48kHz／16-bit双声道FLAC，保持原样，不升采样制造更高规格，不转ALAC。

单段 MKV 保存 FLAC 音轨；MP4 为方便直接播放的 AAC 试听副本。音频来源仍是用户 FLAC，逐样本切段核验与时间范围见 [选段依据](../audio-style-sample-selection.json)。前两段有社区硬字幕＋波形相关支持，未独立听辨逐字起止；第三段没有冒填归乡歌词，正式歌词 JSON 的时间仍为空。
