## 本轮查到的典型误配

1. **T-50 原型图 → Su-57 量产／AC8 模型：**名称沿革不证明同型；本轮在追溯来源、统一比例与实际游戏对照后，仅放行已核的大轮廓基线，不认证现实最新批次。
2. **Rafale B → Rafale M：**即使放在同一型号介绍页，双座机顶视也不能自动套用单座舰载 M 型。
3. **F/A-18C → F/A-18F：**不只是把座舱加长；两者整体机体与进气道等都须分别参照。
4. **通用 MiG-29 → MiG-29A：**图有三视但未证明子型号时，型号验收仍未通过。
5. **Su-35S 顶底／左右侧 → 完整三视：**视图数量多不等于包含正前视。
6. **X-40 完整机体 → 分离机首：**损伤阶段不能互相替代；截图中的火焰与残骸不是正常结构。

后续每次补充资料，保留原来源与版本，更新相应清单的“可用程度”；不把临时参考改名为“官方蓝图”。准确几何与游戏涂装应分别校对，最后在具体镜头的透视中再验收。
