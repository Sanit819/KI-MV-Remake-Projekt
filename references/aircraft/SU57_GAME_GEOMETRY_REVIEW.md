# Su-57／Toprak 022：以 AC8 机模为目标的外形核对

核对日期：2026-11-06。参考版本：**SU57-AC8-BASE-REF-v1**。

**结论：既有同源三视可以作为本片 Su-57 的基础比例与轮廓参考，带以下明确边界通过。** 本轮核实了三视原始出处、三轴尺度自洽，并实际对比 AC8 官方图和 Toprak 前后斜视，未发现机鼻／座舱／翼根布局／进气口位置／尾翼与喷口这些大轮廓上的冲突。不是因为“都叫 Su-57”而通过，也不要求先给游戏机模对应某架现实原型机编号。

这项结论允许进入受参考约束的机体线稿／三维体块阶段；**尚未绘制或验收任何飞机线稿、分镜画面或最终镜头**。游戏未显示清楚的小部件仍未定，不能用最新现实量产机的细节自行补全。

## 1. 三视出处和内部比例已核实

## 2. 实际游戏对比结果

本轮重新检查日站1920×1080官方图、120×120识别小图及已有022细节，并从用户的[入场合集 BV1qsHS6REg9](https://www.bilibili.com/video/BV1qsHS6REg9/)增取5帧。原视频852×480；抽帧保留原始水印、字幕和覆盖层，没有上采样、清图或合成正投影。**没有把这些覆盖层当成 MV 要照抄的内容。**

| 部位 | 图中实际可见的对应 | 本轮判断／绘画约束 |
|---|---|---|
| 机鼻和座舱 | 官方近景与M18／M28均为尖削、横向较扁的前机身；单座舱罩和前风挡框明确。既有三视具有相同基本布局；游戏图未见从鼻尖伸出的长测试探针。 | 基础轮廓可用。低角度官方近景显得鼻部较宽，不能直接认定为另一构型或据此压扁三视。传感器球与小突起的位置按游戏图补，不自由增加长探针。 |
| 主翼与翼根 | M18 91.75／94.00秒可见大面积融合翼根、后掠主翼及进气口上方的前缘面；M28后上斜视可核对主翼后缘与独立平尾的前后关系。 | 基础平面布局可用。不把翼根前缘面画成 Su-33 式独立鸭翼；不把主翼和平尾连成一块。120px官网顶视图仅辅助轮廓识别。 |
| 进气口 | 官方地面图清晰显示座舱后侧、翼根下方的两侧角形进气开口；M18前上斜视能确认分置关系。专利正视具有同样的双侧下置开口布局。 | 位置与外轮廓基准可用。游戏透视不足以量出正视入口的精确倾角、间距或内部斜板；基础截面沿三视，外观回对官方图，不能自行画出未见的内部风道。 |
| 双垂尾、平尾 | 游戏前后斜视可见左右外倾双垂尾、垂尾下部隆起与后方独立平尾；与专利三视的大轮廓对应。 | 可用。按统一三视投影得到倾角；不从某一透视帧直接量角度。垂尾基部小孔／整流包的近景细节仍待清楚游戏视角。 |

[美国官方机型页](https://www.bandainamcoent.com/games/ace-combat-8/aircraft)明确列出 Su-57 Felon。其链接图已下载并实际查看：[美国站竖幅图](source-assets/su-57/ac8-us-official-su57.webp)。它与日本官网主图是同一场景和机位的不同构图，**不计为第二个独立角度**。

UAC 的多个产品页本轮均超时；Rosoboronexport的 [Su-57E PDF](https://roe.ru/pdfs/pdf_6929.pdf)遇到读取超时和证书链错误，未取得文件，不据搜索摘要断言其中有无三视。官方X的 Su-57 介绍帖已定位，但本轮无法取得原图。检索出现的社区自由相机模组未下载、未安装，也没有把可能改模的展示图作为原版游戏几何证据。

因此，不以无法访问厂商页作为失败理由；已经核实的专利原件、同源三视和实际游戏画面可以支持当前这个明确范围的绘画参考。

## 4. 对制作的边界

- **可开始的内容：**依据这套同源三视建立统一比例线稿或体块；做常规远景／中景的顶、侧、前及其受约束透视；用游戏参考补022与金线。制作结果仍须逐镜审核，不能跳过线稿检查。
- **确实还缺的内容：**若镜头要展示完整腹部开舱、对侧近距离传感器、垂尾基部小孔、喷口细部／动作，须补该处游戏视角；不是笼统再要求确认现实生产批次。
- **不可声称：**AC8官方认证工程图、与实际游戏模型毫米级一致、最新量产Su-57完全同型、已经完成机体绘制／镜头验收。

各文件URL、取得日期、实际解码帧时间、SHA-256、许可及读取限制见新来源清单。原件和复核板保留在本地；本轮汇总将新状态关联到共享清单，既有剧情与歌词原稿不因外形核对改变。
